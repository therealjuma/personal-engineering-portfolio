# Personal Engineering Portfolio

A personal website documenting engineering work, technical study,
projects, research and professional development.

## Technology

- Python
- Flask
- Jinja2
- HTML
- CSS
- Vanilla JavaScript

## Setup

Clone or download the project and navigate to its directory.

Create a virtual environment:

    python -m venv .venv

Activate it.

Windows PowerShell:

    .venv\Scripts\Activate.ps1

Linux/macOS:

    source .venv/bin/activate

Install dependencies:

    pip install -r requirements.txt

Run the application:

    python app.py

Open:

    http://127.0.0.1:5000

## Development

This website uses server-rendered HTML through Flask and Jinja.
Content is currently maintained directly in templates.
